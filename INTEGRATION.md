# Руководство по интеграции MegaUltraverse

Это руководство объясняет, как заново сгенерировать ModuleScript MegaUltraverse и корректно подключить его в Roblox Studio. Следуйте шагам по порядку — так вы избежите ошибок и быстро сможете протестировать систему в своей игре.

## 0. Что за файлы и зачем они нужны
- **`build_mega.py`** — это Python‑скрипт, который автоматически собирает огромный ModuleScript. Его нужно запускать каждый раз, когда вы хотите обновить код.
- **`src/MegaUltraverse.lua`** — готовый Lua‑файл. Именно его содержимое нужно вставить в ModuleScript внутри Roblox Studio.
- **Папка `RobloxGame`** — корень проекта. Внутри неё находятся и скрипт генератора, и итоговый Lua‑файл. Все команды в дальнейшем предполагают, что вы находитесь именно в этой папке.

## 1. Скачивание и размещение проекта
1. Откройте страницу проекта на GitHub.
2. Выберите один из способов скачивания:
   - **Если у вас нет Git:** нажмите зелёную кнопку **Code → Download ZIP**, сохраните архив в удобное место (например, `Документы`), затем распакуйте его. После распаковки появится папка `RobloxGame` — это и есть нужный корень проекта.
   - **Если Git установлен:** откройте терминал/PowerShell и выполните `git clone <адрес_репозитория>`. Команда создаст папку `RobloxGame` в текущем каталоге.
3. Убедитесь, что внутри папки `RobloxGame` лежат файлы `build_mega.py`, `INTEGRATION.md` и папка `src`. Если их нет, переместите загруженные файлы туда вручную (обычным перетаскиванием в проводнике/файловом менеджере).
4. Откройте папку `RobloxGame` в проводнике (Windows) или Finder (macOS), чтобы убедиться в структуре:
   ```
   RobloxGame/
     build_mega.py
     INTEGRATION.md
     src/
       MegaUltraverse.lua
   ```

## 2. Как открыть терминал именно в папке `RobloxGame`
Терминал — это окно, куда вводятся команды. Важно, чтобы текущей директорией была папка проекта.

### Windows
1. Откройте проводник и перейдите в папку `RobloxGame`.
2. Кликните по адресу (вверху) и введите `powershell`, затем нажмите **Enter**. Откроется окно PowerShell уже в нужной папке.
   - Альтернатива: в проводнике нажмите правой кнопкой мыши внутри папки → **Открыть в Терминале** / **Open in Terminal** (Windows 11) или **Открыть окно PowerShell здесь** (Windows 10).

### macOS
1. Откройте Finder и перейдите в `RobloxGame`.
2. Нажмите правой кнопкой по свободному месту → **Новый терминал в папке** (если установлен пакет «Services»), либо откройте стандартное приложение **Terminal** и перетащите папку `RobloxGame` в окно терминала — путь заполнится автоматически. Нажмите **Enter**.

### Linux
1. Откройте файловый менеджер, перейдите в `RobloxGame`.
2. Нажмите правой кнопкой → **Открыть в терминале**. Если опции нет, запустите терминал вручную и используйте команду `cd /путь/к/RobloxGame`.

Проверьте, что вы находитесь в правильной папке, командой `pwd` (macOS/Linux) или `Get-Location` (Windows PowerShell). В ответе должно быть что-то вроде `.../RobloxGame`.

## 3. Подготовка окружения
1. Установите **Python 3.10** или новее. Скачать можно с [python.org](https://www.python.org/downloads/) (Windows/macOS) или из менеджера пакетов (Linux). После установки проверьте командой `python --version`.
2. Убедитесь, что установлен **Roblox Studio** и вы вошли в свою учётную запись.
3. (Необязательно, но полезно) Создайте виртуальное окружение Python, чтобы изолировать зависимости проекта:
   ```bash
   python -m venv .venv
   # macOS/Linux
   source .venv/bin/activate
   # Windows PowerShell
   .venv\Scripts\Activate.ps1
   ```

## 4. Генерация ModuleScript
1. Находясь в терминале внутри папки `RobloxGame`, выполните команду:
   ```bash
   python build_mega.py
   ```
   Если система сообщает `python` не найден, попробуйте `py` (Windows) или `python3` (macOS/Linux).
2. Скрипт автоматически перезапишет файл `src/MegaUltraverse.lua`, создавая актуальную версию ModuleScript. В консоли появятся строки вида `[MegaBuilder] Listing MegaUltraverse content blocks...` и `[MegaBuilder] Compiling MegaUltraverse.lua -> wrote XXXX lines to ...` — они подтверждают успешную генерацию.
3. Чтобы убедиться, что генератор не содержит синтаксических ошибок, можно дополнительно выполнить:
   ```bash
   python -m compileall build_mega.py
   ```
   Если ошибок нет, появится строка вроде `Compiling 'build_mega.py'...` без предупреждений и исключений.

## 5. Импорт в Roblox Studio
1. Запустите Roblox Studio и откройте нужное место (Place).
2. В окне **Explorer** найдите контейнер, в котором хотите хранить модуль (рекомендуется **ReplicatedStorage** для общих систем).
3. Кликните правой кнопкой по выбранному контейнеру → **Insert Object** → выберите **ModuleScript**.
4. Переименуйте созданный объект в **MegaUltraverse** (важно для последующего `require`).
5. Откройте файл `src/MegaUltraverse.lua` в любом текстовом редакторе, выделите весь код (Ctrl+A) и скопируйте (Ctrl+C).
6. Вернитесь в Roblox Studio, откройте созданный ModuleScript и замените шаблонный код на скопированный (Ctrl+V).
7. Нажмите **Ctrl+S / ⌘+S**, чтобы сохранить изменения в проекте.

## 6. Подключение систем в игре
1. Создайте новый **Script** в **ServerScriptService** (именно Script, а не LocalScript), назовите, например, `MegaBootstrap`.
2. Вставьте следующий код, чтобы инициализировать систему:
   ```lua
   local ReplicatedStorage = game:GetService("ReplicatedStorage")
   local MegaUltraverse = require(ReplicatedStorage:WaitForChild("MegaUltraverse"))

   MegaUltraverse:Boot()
   ```
   Метод `Boot()` теперь отслеживает повторные вызовы: если скрипт запустится дважды, в консоли появится предупреждение, а система не инициализируется повторно. Для аккуратной остановки предусмотрен метод `MegaUltraverse:Shutdown()`, который отключает Heartbeat-подписку сервера.
3. Убедитесь, что все дополнительные модули, на которые ссылаются таблицы `MegaUltraverse.Config`, `MegaUltraverse.Systems` и `MegaUltraverse.Registries`, находятся в игре и имеют корректные пути.
4. После запуска в режиме **Play** или **Start Server** проверьте выход консоли на наличие предупреждений и ошибок — они помогут понять, чего не хватает или что настроено неправильно.

## 7. Советы по автоматизации
- Чтобы не копировать код вручную, можно настроить CI/CD-пайплайн, который будет запускать `python build_mega.py`, а затем выгружать свежий `MegaUltraverse.lua` на приватный веб-сервер. После этого в Roblox Studio можно выполнять автоматический импорт через `HttpService:GetAsync` и `ModuleScript.Source = ...` в режиме плагина или команды в Command Bar.
- Для командного импорта откройте панель **View → Command Bar** и используйте свои скрипты, вызывающие `InsertService` или `HttpService`, чтобы загрузить модуль напрямую в Roblox Studio.

Следуя этим шагам, вы сможете без труда внедрить MegaUltraverse в любой свой Roblox-проект и при необходимости обновлять модуль столько раз, сколько потребуется.
